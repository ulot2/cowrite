Where each piece goes

Everything a draft collects stays attached to the words it is about.

  1. A chat thread about the draft →

    Comments on the exact words

    Select a sentence and comment. Reply, react, mention someone with @, resolve it when it is settled.

    need the new iconMIs Friday realistic? @Tom
  2. plan_v3_FINAL (2).docx →

    One live document, every version kept

    Everyone types in the same place at once. Versions save by themselves; compare any two and restore one.

    Sent to reviewTom · 2 h agoAutomaticMaria · yesterday
  3. A spreadsheet of changes to approve →

    Suggestions and a status

    Reviewers suggest instead of overwriting. Editors accept or reject each change, then move the document from Draft to Approved.

    We launch on March 3April 10Draft→In review→Approved
  4. A to-do list and “what did we decide?” →

    Tasks and decisions in the text

    Type /task to assign work with a date; it shows on that person’s Tasks page. Type /decision to record a numbered decision for the space’s log.

✦ Nib, the writing assistant

Nib suggests. You decide.

Ask Nib to improve, shorten, or continue a passage, or type @nib and anything you want. Its answer arrives as a suggestion, marked as Nib’s, so nothing changes until someone accepts it.

  • Fix spelling and grammar
  • Make shorter
  • Summarize
  • Extract action items

How it is built

For the curious. Every document is its own small server that holds the text as a CRDT, so edits from any number of people and devices merge the same way everywhere.

  • 42 automated tests on every push
